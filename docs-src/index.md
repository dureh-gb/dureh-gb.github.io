# 두레공방 Docs

두레공방 (Dureh Gong-bang) is a small workshop that builds private tools for working across your own computers: Mac, Linux, Windows and phone. The tools run over the connections you already trust, such as SSH. Your data stays yours, and nothing is collected. The names come from Korean village life, when neighbours worked the fields together: *dureh* is the village work group, *gong-bang* is a workshop.

This site documents each module. Pick one below.

## Modules

<div class="grid cards" markdown>

-   **두레 Dureh**

    ---

    A desk for all your computers: terminal, files, port forwards, remote screens and agents in one window. Register each computer as a node and pin its SSH host key.

    [Dureh documentation](dureh/index.md)

-   **품앗이 Pumasi**

    ---

    See and control your own computers over SSH. The host opens no ports and uses no cloud relay. Sharing is visible on the host.

    [Pumasi documentation](pumasi/index.md)

-   **품앗이 뷰어 Pumasi Viewer**

    ---

    The viewer side of Pumasi: watches a host's screen and sends keyboard and mouse input over the SSH connection.

    [Pumasi Viewer documentation](viewer/index.md)

-   **마실 Masil**

    ---

    Drop in on your computers from a Windows PC or your phone. One launcher for your remote desktops on Windows; Pumasi Viewer, an SSH terminal and file transfer on Android.

    [Masil documentation](masil/index.md)

-   **문지기 Munjigi**

    ---

    The session gatekeeper for Linux nodes: brings an account's desktop session back to the screen, or starts one, so Pumasi has something to show. Never asks for a password.

    [Munjigi documentation](munjigi/index.md)

</div>
