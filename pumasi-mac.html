Setup guide설정 안내

MacUse a Mac as a Pumasi hostMac을 품앗이 호스트로 쓰기

Five steps, about ten minutes, done once at the Mac itself. You need an administrator password for the install and a Windows PC with Pumasi Viewer or Masil to connect from. macOS 13 (Ventura) or later.

다섯 단계, 10분 정도이며 Mac 앞에서 한 번만 하면 됩니다. 설치에 관리자 암호가 필요하고, 접속할 Windows PC에 품앗이 뷰어나 마실이 있어야 합니다. macOS 13(Ventura) 이상.

  1. Turn on Remote Login

    원격 로그인 켜기

    Pumasi uses the Mac's own SSH login; it opens no other port.

    품앗이는 Mac 자체의 SSH 로그인을 씁니다. 다른 포트는 열지 않습니다.

    • System Settings → General → Sharing, turn on Remote Login.
    • 시스템 설정 → 일반 → 공유에서 원격 로그인을 켭니다.
    • Click ⓘ next to it and allow only the account you will log in with.
    • 옆의 ⓘ를 눌러, 로그인할 계정만 허용합니다.

  2. Install the package

    패키지 설치

    Pumasi is in private beta: the package Pumasi-<version>.pkg and its SHA-256 come with your invitation. Check the file before you open it:

    품앗이는 비공개 베타입니다. 패키지 Pumasi-<버전>.pkg와 그 SHA-256은 초대와 함께 받습니다. 열기 전에 파일을 확인하세요.

    shasum -a 256 ~/Downloads/Pumasi-*.pkg

    The two values must be the same. Log in at the Mac's screen as the account that will be shared, then open the package.

    두 값이 같아야 합니다. 공유할 계정으로 Mac 화면에 로그인한 상태에서 패키지를 엽니다.

  3. Pass the unsigned-build warning

    서명되지 않은 빌드 경고 넘기기

    The beta has no Apple Developer ID, so macOS stops it the first time. Open it only if the SHA-256 matched.

    베타에는 Apple Developer ID 서명이 없어서 macOS가 처음에 막습니다. SHA-256이 맞았을 때만 여세요.

    macOS 15 and later
    Double-click the package. The dialog says “Pumasi-….pkg” Not Opened · Apple could not verify … is free of malware; click Done. Then System Settings → Privacy & Security, scroll to “Pumasi-….pkg” was blocked to protect your Mac, click Open Anyway, enter your password and click Open.
    패키지를 두 번 클릭합니다. “Pumasi-….pkg”이(가) 열리지 않음 · Apple은 … 악성 코드가 없음을 확인할 수 없습니다 창이 뜨면 완료를 누릅니다. 그다음 시스템 설정 → 개인정보 보호 및 보안에서 “Pumasi-….pkg”이(가) Mac을 보호하기 위해 차단되었습니다까지 내려가 그래도 열기를 누르고, 암호를 입력한 뒤 열기를 누릅니다.
    macOS 13–14
    In Finder, Control-click the package, choose Open, then Open again in the warning.
    Finder에서 패키지를 Control-클릭하고 열기를 고른 뒤, 경고 창에서 다시 열기를 누릅니다.

    The installer asks for an administrator password, puts Pumasi.app in Applications and starts it. A Pumasi item appears in the menu bar.

    설치 프로그램이 관리자 암호를 묻고, 응용 프로그램 폴더에 Pumasi.app을 넣고 실행합니다. 메뉴 막대에 품앗이 항목이 나타납니다.

  4. Allow the permissions

    권한 허용

    The Set up Pumasi… window opens by itself (later: from the menu bar item). Each line has an Open Settings button; Pumasi changes no setting itself. In System Settings → Privacy & Security, turn on Pumasi in:

    Set up Pumasi… 창이 저절로 열립니다(나중에는 메뉴 막대 항목에서 엽니다). 줄마다 Open Settings 버튼이 있고, 품앗이가 스스로 설정을 바꾸지는 않습니다. 시스템 설정 → 개인정보 보호 및 보안의 다음 항목에서 Pumasi를 켭니다.

    • Screen & System Audio Recording: the picture.
    • 화면 및 시스템 오디오 녹음: 화면.
    • Accessibility: remote keyboard and mouse.
    • 손쉬운 사용: 원격 키보드와 마우스.
    • Input Monitoring: the privacy curtain.
    • 입력 모니터링: 가림막(커튼).

    If macOS asks to quit and reopen Pumasi, do so. Without a Developer ID, macOS may ask again after an update.

    macOS가 품앗이를 종료 후 다시 열라고 하면 그렇게 합니다. Developer ID가 없어서 업데이트 뒤에 다시 물을 수 있습니다.

  5. Add the Mac on your PC

    PC에서 Mac 추가

    The Set up window shows this Mac's address (its ….local name) and the account name. On the PC, Pumasi Viewer logs in with an SSH key, never a password: add the key's public part to ~/.ssh/authorized_keys of that account on the Mac first.

    Set up 창에 이 Mac의 주소(….local 이름)와 계정 이름이 나옵니다. PC의 품앗이 뷰어는 암호가 아닌 SSH 키로 로그인합니다. 먼저 그 키의 공개 키를 Mac의 해당 계정 ~/.ssh/authorized_keys에 넣으세요.

    • Masil: + → Pumasi node…. Pumasi Viewer: Add node….
    • 마실: + → Pumasi node…. 품앗이 뷰어: Add node….
    • Enter the address and account, and pick the login key: a key in the Windows OpenSSH agent, or a key file.
    • 주소와 계정을 넣고 로그인 키를 고릅니다. Windows OpenSSH 에이전트의 키나 키 파일입니다.
    • Check host key, compare it with the Mac's, tick This is the node's SSH host key.
    • Check host key를 누르고 Mac의 값과 비교한 뒤 This is the node's SSH host key에 체크합니다.
    • Log in and check Pumasi, then tick This is the Pumasi build installed on my node and Save.
    • Log in and check Pumasi를 누른 뒤 This is the Pumasi build installed on my node에 체크하고 Save를 누릅니다.

    To see the Mac's host key, run this in Terminal on the Mac:

    Mac의 호스트 키는 Mac의 터미널에서 이렇게 확인합니다.

    for f in /etc/ssh/ssh_host_*_key.pub; do ssh-keygen -lf "$f"; done

    Then double-click the node to connect. The Mac's menu bar shows when it is being shared.

    이제 노드를 두 번 클릭해 접속합니다. 공유 중이면 Mac의 메뉴 막대에 표시됩니다.

Remove it

제거

The menu's Uninstall Pumasi… shows a command to run in Terminal as the logged-in user (not with sudo). Afterwards, remove Pumasi from the three Privacy & Security lists yourself.

메뉴의 Uninstall Pumasi…가 터미널에서 실행할 명령을 보여 줍니다. 로그인한 사용자로 실행하세요(sudo 없이). 그다음 개인정보 보호 및 보안의 세 목록에서 Pumasi를 직접 지웁니다.
